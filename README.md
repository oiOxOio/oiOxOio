  <summary>关于我 · 文字版</summary>

我是 **oiOxOio / Why.Ping**，一名全栈开发者，关注从界面到服务端的完整开发过程。重视清晰的代码、自然的交互和持续迭代，保持对新技术与开发工具的好奇。

我关注的方向：

- **前端开发**：关注清晰的界面、自然的交互，以及响应式布局、性能和使用体验。
- **后端开发**：围绕接口、数据与服务组织代码，兼顾稳定性、扩展性和可维护性。
- **工程实践**：重视代码结构、版本管理与自动化，让开发、部署和维护更顺畅。
- **持续学习**：在实践中了解新技术、验证新工具，持续改进自己的开发方式。

技术选择：

- **后端**：Java、Spring Boot、PostgreSQL。
- **前端**：Vue、shadcn。
- **基础设施**：Kubernetes（K8s）、Docker。
- **AI 工具**：ChatGPT、Codex。

**AI 偏好**：结合对话梳理思路与 Agent 编码，先明确目标、补足上下文，再通过代码审查与实际验证确认结果。

把想法写成代码，让体验持续变好。
